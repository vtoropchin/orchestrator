# Проверка и упрощение публичных скилов

Дата: 2026-11-09. Исходная версия: `09adf40`.

## Область и допущения

Проверены два разработанных в проекте пакета: `skills/orchestrate` и
`skills/session-worker`, включая их ресурсы. Служебные `.claude/skills/`, настройки,
внешние установленные скилы и пользовательские незакоммиченные файлы не изменяются.
Целевая модель редакторской проверки и сценариев — Claude Opus 5.5.
Это упрощение существующего контракта v3, не проектирование нового протокола.

намеренно остаётся общий контракт: ссылка на соседний пакет нарушила бы переносимость.
Сокращение текста само по себе не доказывает улучшение качества или экономию токенов.

## Как проверять результат

- **S:** официальный валидатор метаданных, синтаксис оболочки, review-lint, локальные
  ссылки/границы пакетов и согласованность схем старой/новой версий.
- **F:** парные сценарии из [skill-evals.json](../tests/skill-evals.json): обычная
  read-only работа/бюджет/resume; отсутствие evidence-пути и старый grant; Git-фазы,
  чужой clone, неполные criteria и literal filenames. Это симуляция решений моделью,
  а не запуск реальных Desktop-сессий.
- **F/GitCLI:** временный Git-репозиторий проверяет точное staging имён с `[]` и
  pathspec magic; соседние файлы не должны попасть в index. Hardlink проверяется
  по физической идентичности, не по строке пути.
- **Установка:** закреплённый `skills@1.7.6`, `--copy`, Claude Code, без `-g`,
  в три новых временных проекта: orchestrate отдельно, session-worker отдельно, оба.
  Сверяется содержимое всех скопированных файлов и отсутствие симлинков наружу.

**Не проверяется этим набором:** реальный R-smoke Desktop/memo, доставка сообщений,
поведение клиента при сбое, измеренная экономия контекста/денег и автоматический выбор
скила по description. Сценарии по одному прогону на версию — проверка сохранения решений,
не статистическое доказательство качества.

Команда установки из каждого нового временного consumer-проекта:

```bash
DISABLE_TELEMETRY=1 npx --yes skills@1.7.6 add /path/to/Skills/skills --skill orchestrate session-worker -a claude-code --copy -y
```

Для одиночной установки передавалось только соответствующее имя. Полные временные журналы
установки и прогоны не являются ресурсами публичных пакетов.

[HTML-отчёт официального eval-viewer](skill-review.html) содержит prompt, outputs,
формальные оценки и benchmark. `with_skill` — новая версия, `old_skill` — исходная,
не запуск без скила. Все проверки проходят в обеих версиях: это отсутствие регрессии
в данных сценариях, а не доказанное улучшение точности. Harness timing/tokens включают
унаследованный контекст среды авторинга и не измеряют отдельно стоимость скила или parent.

Первоначальная проверка argv ошибочно отклонила безопасный вариант baseline с дополнительным
`git -C /repo-A/work`. Проверка исправлена для обеих версий: допускает этот вариант
и проверяет literal mode, точный checkout и два точных имени. Выходы моделей не менялись.
Проверка ссылок также исключает примеры Desktop-ссылок внутри code, не принимая их за файлы.

### Границы результата

Риск: средний — исполняемые текстовые инструкции `skills/**`; high/security-пути REVIEW.md
не менялись. `/security-review` не требовался. Протокол v3 не изменён; живой R-smoke
Desktop/memo и измерение экономии не выполнялись и не заявляются. Коммит локальный,
без push и публикации. Откат — `git revert` коммита упрощения.
